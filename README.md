# 🎯 Dart-turnering

Tre sider til en dart-aften:

- **index.html**: Turneringsplan og indtastning. Åbn **Storskærm** for livescore med stilling, finaler, rulletekst og 180-show.
- **index.html#skaerm**: Selve storskærmen. Den opdaterer sig selv, når der tastes ind i samme browser.
- **scorer.html**: Hartvig Dart Score, en scorer til 501, 301 og Cricket. Du kan sige scoren med stemmen (Chrome eller Edge), trykke på felt-knapperne eller taste den.

Alt gemmes lokalt i browseren. Kør lokalt ved at dobbeltklikke på `Start dart.command`.
